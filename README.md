# Website CV Fabian Teknik

Demo website company profile CV Fabian Teknik (Glagahan, Perak, Jombang), dibuat oleh Zira Digital.

- Framework: Astro + Tailwind CSS
- Hosting: Netlify (`npm run build`, folder `dist`)
- Data kontak dan daftar mesin: `src/data/site.js`

```bash
npm install
npm run dev
```
